# Expense Tracker CLI

A lightweight Python command-line application demonstrating math operations and the **accumulator pattern** (`total = total + new_expense`).

## Features
- Dynamic expense entry
- Live running total calculation
- Category-based summaries
- Input validation and unit tests

## How to Run

1. **Run the Application:**
   ```bash
   python main.py
   ```

2. **Run Tests:**
   ```bash
   pip install -r requirements.txt
   pytest test_tracker.py
   ```
